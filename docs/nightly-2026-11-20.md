## Controlled physical-console acceptance plan

RC 11 is ready for this controlled test on separate media. Run it in a
separate deployment task. Prepare a dedicated test SD or
a separate explicitly approved test installation with disposable worlds,
profiles, and pairing credentials. Keep the verified 0.7.0 SD and its
rollback build available. Record the candidate and prepared 26.3 resource
hashes, the console setup, and whether it boots the WUHB or RPX. Verify the
staged file against the private build receipt before first launch.

1. Cold boot into Night. Check correct TV and GamePad output, navigation and
   saved controller preferences. Verify a scoped local HTTPS pairing on the
   test profile. Record the initial heap markers and compare stock console
   entropy initialization with the Cemu-only NSS limitation.
2. Open the copied world at render and simulation distance 12. Confirm
   terrain, the lightmap, HUD, controller response, and audible game and
   menu sounds through the intended outputs. Capture both displays and
   collect startup, worker, heap, and GX2 frame telemetry.
3. Place or remove a known block and record its coordinates. Use HOME and
   return once from gameplay and once from Night. Verify both displays,
   controller input, audio resume, and scoped MCP behavior on return.
4. Save & Quit, confirm the save barrier, worker drain and tool withdrawal,
   then reopen the same world from Night in that process. Confirm the block
   change and make a second change. Repeat Save & Quit, hash the copied
   `level.dat` and changed region files after the barrier, then cold boot and
   reopen for readback. Preserve a copy of each saved state and diagnostic
   trace.
5. Compare both post-session heap snapshots with the pre-session free space
   and largest block. Repeat the two-launch sequence under an approved,
   representative memory workload. Record any allocation failure, retained
   resources, launch timeout, or frame pacing regression and keep the
   last test save intact for diagnosis.

Physical acceptance stays pending until this sequence passes on the
console. Measure frame timing on hardware. SDK and dependency path cleanup,
redistribution review, production signing and physical acceptance remain
separate preconditions for public binary publication.
