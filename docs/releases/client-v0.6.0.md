# Wii U client 0.6.0

The Night launcher supports offline local profiles, compatible installations, saved-world selection and handoff to the native Cafe game. GamePad controls and TV rendering use the native host.

The [original Night record](../night-local-validation.md) documents the baseline's exact build and Cemu evidence. The path-sanitized public patch changes the staged source tree and build receipt identity. Hardware acceptance of public packages remains pending, including saved-world reopening.
