# RC 48 build and qualification

RC 48 binds automated benchmark cancellations to the run ID and
registered client. The Cafe renderer resolves the pack-defined default
post chain at resource installation. Active post effects still report
omissions. [Benchmark contract](benchmarks.md#start-and-retrieve-through-mcp)

## Runtime evidence

An earlier instrumented tree with the same benchmark ownership patch
reused the approved grant in Cemu. It cancelled two consecutive
stationary requests with matching run IDs. Night refused the first ID
after the second request started, and both valid cancellations returned
to Home. A separate full-scope client was refused in the exact-source
host test. No timed benchmark was collected in the cancellation test.

The official RC 48 package still needs its live smoke and the supervised
console run. The physical 60 FPS criterion remains the independent
TV and GamePad workload with the fixed 75% saved pose.
